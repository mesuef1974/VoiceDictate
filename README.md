# سلمى — إملاء ومحادثة صوتية عربية محلية على Windows

أداة واحدة (`dictate.pyw`) تعمل كلها على الجهاز بلا إنترنت:

- **إملاء**: Whisper (faster-whisper، large-v3-turbo على كرت الشاشة) يكتب ما تقوله بالعربية الفصحى في أي برنامج، مع أوامر صوتية (أرسل، سطر جديد، امسح، حدد الكل…).
- **محادثة**: نموذج لغوي محلي عبر LM Studio (Qwen3-8B) يجيب بصوت **سلمى** (SILMA TTS على كرت الشاشة في خادم مستقل) أو كريم (Piper) احتياطًا.
- **تشكيل قبل النطق**: text2tashkeel (rawi) + معجم تصحيح `tashkeel.txt` + وقف أواخر الكلمات + ترتيب الشدة قبل حركتها كما تتوقع نماذج النطق.
- **لوحة عائمة** مربعة بخط Cairo: سحابة جسيمات ثلاثية الأبعاد تتحرك مع صوتك وصوت سلمى، مفتاح «إملاء | محادثة»، نص يضيء كلمةً كلمة مع النطق، وضع مصغّر، تلاشٍ عند السكون، أيقونة شريط المهام، وتكبير بالسحب.

## المفاتيح

| المفتاح | الفعل |
|---|---|
| Ctrl+Alt+F9 | تشغيل التسجيل وإيقافه |
| Ctrl+Alt+F10 | التبديل بين الإملاء والمحادثة |
| Ctrl+Alt+F11 | تصغير اللوحة وتوسيعها |

## التشغيل

1. `python -m venv .venv` ثم تثبيت: `faster-whisper piper-tts sounddevice numpy text2tashkeel num2words pillow pystray arabic-reshaper python-bidi fonttools`.
2. نماذج Piper في `models/piper/` (ar_JO-kareem-medium)، وخط Cairo في `fonts/` (رخصة OFL مرفقة).
3. خادم سلمى في مجلد شقيق `../SilmaTTS` (بيئة torch منفصلة، `server.py`)؛ بدونه تعمل الأداة بكريم.
4. LM Studio يعمل على المنفذ الافتراضي ونموذج `qwen/qwen3-8b` محمّل للمحادثة.
5. `start.cmd` يشغّل الأداة بلا نافذة طرفية.

الملفات الشخصية (السجلات، الموضع، الصوت المختار، المصطلحات) خارج المستودع.
